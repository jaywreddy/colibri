### OFL compliance notes for this repo

- The OFL permits bundling, embedding, and redistribution of the font (including
  with commercial software) provided the font is not sold *by itself* and the
  Reserved Font Name is not applied to derivative font files.
- We do **not** create or redistribute a derivative *font* file — we only
  rasterize glyphs into a binary silhouette mask at build time
  (`monogram.py`). Rasterized artwork ("documents created using the font") is
  explicitly exempt from the OFL's copyleft per the license PREAMBLE.
- The unmodified `.ttf` and its `OFL.txt` are shipped side by side to satisfy the
  redistribution requirement that the license accompany the Font Software.
