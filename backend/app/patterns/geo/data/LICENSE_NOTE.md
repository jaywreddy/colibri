# Vendored geographic data — Natural Earth (Public Domain)

These files are from **Natural Earth**, a public-domain map dataset.

- `ne_110m_land.geojson` — 1:110m land polygons (coastlines).
- `ne_110m_admin_0_countries.geojson` — 1:110m country polygons (used for the
  Colombia highlight lookup by the `NAME`/`ADMIN` property).
